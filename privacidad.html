02

Qué datos tratamos

El formulario recoge la descripción del proyecto, el tipo de consulta, nombre, correo electrónico, empresa y cargo o responsabilidad. El teléfono, las capacidades relacionadas, la etapa de la empresa y el rango de presupuesto son opcionales. También registramos el contexto o nota desde el que llegaste, la página de origen, la fecha de envío y la aceptación de esta política.

La dirección IP se utiliza temporalmente en la infraestructura de MEDLA para limitar intentos automatizados. No se incorpora al mensaje remitido a HighLevel / LeadConnector.

No pedimos categorías especiales de datos. Evita incluir información médica, ideológica, biométrica u otros datos especialmente protegidos en el campo de notas.

03

Para qué y con qué base

Usamos la información para entender la solicitud, comprobar si MEDLA puede atenderla y responder por el canal facilitado. No se utiliza para enviarte comunicaciones comerciales ajenas a esa conversación sin una elección separada.

La base jurídica es tu consentimiento al enviar el formulario y, cuando solicitas una propuesta o servicio, la aplicación de medidas precontractuales a petición tuya. Puedes retirar el consentimiento sin afectar al tratamiento realizado previamente.

Las selecciones indicadas como obligatorias y los campos marcados con asterisco son necesarios para responder. Si no los completas, el formulario no podrá enviarse.

04

Durante cuánto tiempo

Conservamos los datos mientras atendemos la solicitud y existe una conversación activa. Si no se inicia una relación profesional, se mantendrán únicamente durante el tiempo necesario para gestionar la consulta y las posibles responsabilidades; después se eliminarán o bloquearán.

Cuando sea necesario, determinada información podrá bloquearse durante los plazos exigidos para atender responsabilidades legales. Si se inicia una relación contractual, se aplicarán los plazos correspondientes a esa relación y se facilitará la información adicional que proceda.

05

Proveedores y transferencias

El formulario transmite la solicitud a la infraestructura de HighLevel / LeadConnector, utilizada como proveedor tecnológico para recibir y organizar contactos. También pueden intervenir proveedores de alojamiento y soporte estrictamente necesarios para operar la web.

Según su documentación, HighLevel / LeadConnector utiliza el Marco de Privacidad de Datos UE–EE. UU. y cláusulas contractuales tipo cuando resultan aplicables. Puedes solicitar información sobre estas garantías en info@medla-empresas.com.

No vendemos los datos enviados mediante el formulario ni los cedemos a terceros para su publicidad.

06

Tus derechos

Puedes solicitar acceso, rectificación, supresión, limitación, oposición y portabilidad, así como retirar el consentimiento cuando corresponda.

Escribe a info@medla-empresas.com con el asunto “Protección de datos” e indica qué derecho deseas ejercer. Podremos pedir la información estrictamente necesaria para confirmar tu identidad.

Si consideras que el tratamiento no es correcto, puedes reclamar ante la Agencia Española de Protección de Datos.

07

Navegación y terceros

La versión actual de esta web no incorpora analítica publicitaria ni seguimiento propio de comportamiento. Para mostrar las tipografías, el navegador solicita archivos a Google Fonts; esa petición puede comunicar a Google la dirección IP y datos técnicos básicos del dispositivo.

Los enlaces a WhatsApp u otros servicios externos pueden realizar tratamientos sujetos a sus propias políticas cuando decides utilizarlos.

Si en el futuro se incorporan tecnologías no necesarias que requieran consentimiento, se ofrecerán opciones visibles para aceptarlas o rechazarlas antes de su activación.

08

Seguridad, decisiones y cambios

El formulario transmite la información mediante una conexión HTTPS. Ningún canal elimina por completo el riesgo; por eso pedimos no incluir documentación ni datos sensibles en el primer contacto. La solicitud no se resuelve mediante una decisión exclusivamente automatizada con efectos jurídicos sobre ti.

Actualizaremos esta página cuando cambien el formulario, sus proveedores o las finalidades. La fecha visible al inicio permite identificar la versión aplicable.
